# Synapse - React Version

A modern, dynamic React.js implementation of the Synapse interface with animated backgrounds and interactive features.

## Features

- **Pure React.js** - No external CSS frameworks, all styling done with React inline styles
- **Dynamic Background** - Animated floating orbs, mouse-following gradients, and particle effects
- **Theme Toggle** - Smooth dark/light theme switching with persistent storage
- **Interactive Components** - Hover animations, drag & drop functionality, and smooth transitions
- **Responsive Design** - Mobile-first approach with adaptive layouts
- **Framer Motion** - Smooth animations and micro-interactions throughout

## Components

- **Header** - Navigation with theme toggle and mobile menu
- **Hero** - Animated landing section with floating cards
- **Tools** - Interactive tool cards with hover effects
- **How It Works** - Step-by-step process with unique animations
- **Pricing** - Dynamic pricing card with animated elements
- **CTA** - Drag & drop file upload with real-time feedback
- **Footer** - Animated footer with social links

## Dynamic Features

- **Floating Orbs** - Multiple animated orbs with different colors and movements
- **Mouse Tracking** - Background elements that follow mouse movement
- **Particle System** - Subtle animated particles for visual interest
- **Gradient Animations** - Smooth color transitions and gradient shifts
- **Hover Effects** - Interactive elements that respond to user interaction
- **Loading States** - Smooth loading animations and transitions

## Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm start
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```

## Dependencies

- **React 18** - Core framework
- **Framer Motion** - Animation library
- **React Scripts** - Build tooling

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

## Performance

- Optimized animations with `will-change` properties
- Efficient re-renders with React hooks
- Smooth 60fps animations
- Responsive design for all screen sizes

## Customization

The theme system allows easy customization of colors and styles. All components use the theme prop to adapt their appearance dynamically.
